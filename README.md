# Sunday Club

Playable browser build of the original pickleball game defined in Game-Intelligence2/pickleball2.

Not a licensed PPA / MLP simulation. Club-first original IP. Doubles is the default. The kitchen is sacred.

## Play

Open `index.html` in a modern browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Controls

WASD move, hold Space or click to swing, 1-8 shot families, Q/E/R/F/C doubles calls, P pause, backtick debug.

Source documents live in https://github.com/Game-Intelligence2/pickleball2
